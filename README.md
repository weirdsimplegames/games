# Climb, Cube, Climb!\n\nA browser-based precision climbing platformer built with vanilla HTML, CSS, and JavaScript.\n\n## Play\nOpen `index.html` in a modern browser, or enable GitHub Pages for this repository and visit the published site. No build tools or dependencies are required.\n\n## Controls\n- **A / D** or **← / →**: move\n- **Hold Space / ↑ / W**: charge a jump; release to launch\n- **Shift**: Burst (unlocks at 900m)\n- **E**: Freeze (unlocks at 1,800m)\n- **P / Esc**: pause\n- On touchscreens, use the on-screen controls.\n\nThe game uses original browser-drawn visuals and generated platform layouts.
